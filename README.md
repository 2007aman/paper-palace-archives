# 🏛️ Paper Palace Archives

A sophisticated digital sanctuary for archiving, categorizing, and exploring curated documents and media. Paper Palace Archives blends a minimalist aesthetic with powerful organizational tools.

## ✨ Features

- **Digital Vault:** Securely store and categorize diverse document types.
- **Advanced Search:** Quick retrieval using metadata and tags.
- **Responsive Design:** Seamless experience across desktop and mobile devices.
- **Cyberpunk Aesthetic:** A modern, high-contrast UI designed for clarity and style.

## 🛠️ Tech Stack

- **Frontend:** [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Components:** [Shadcn UI](https://ui.shadcn.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/2007aman/paper-palace-archives.git](https://github.com/2007aman/paper-palace-archives.git)
   cd paper-palace-archives

    Install dependencies:
    Bash

    npm install

    Start the development server:
    Bash

    npm run dev
